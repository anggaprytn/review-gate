# Contributing

Thanks for contributing to ReviewGate.

## Scope

ReviewGate v0.1 is focused on local-first GitLab merge request review. Please keep changes aligned with the current scope:

- GitLab merge request review.
- Summary publishing and optional inline publishing.
- Verification of previous findings.
- Local SQLite history.
- Providers: `gemini_cli`, `codex_cli`, and `ollama`.

Please do not add dashboard, SaaS backend, GitHub provider support, Semgrep integration, Docker packaging, or direct model API providers without prior discussion.

## Development

Run the standard checks before opening a pull request:

```bash
cargo fmt --all -- --check
cargo check
cargo test
```

If you touch CLI behavior, update the README and relevant docs.

## Security And Privacy

Do not commit tokens, private merge request data, raw prompts, raw model payloads, or private planning documents. `docs/PRD.md`, `.env`, and `.reviewgate/` are intentionally ignored.

All generated GitLab comments must keep visible attribution:

```text
[AI generated by ReviewGate]
```

Hidden ReviewGate markers must remain present for dedupe and update behavior.
